# Stardew Valley 1.6.15 Action Reconciliation

These files are generated by `StardewAI.KnowledgeCompiler` from the locked
1.6.15 knowledge export, runtime assemblies, live snapshot, and decompile root.

- `native-action-surface-inventory.json`: native input-bearing source surfaces.
  It is source evidence, not the semantic action denominator.
- `semantic-action-catalog.json`: registered OptionSpecs plus source-proven
  semantic actions catalogued as blocked while their contracts are absent.
- `action-implementation-reconciliation.json`: ownership of every currently
  registered option by one primary engine, plus compiler/runtime orphan checks.
- `action-progress-dashboard.json`: fixed-stage counts. Registered option count
  must never be reported as whole-game completion while
  `semantic_denominator_status` is not frozen.

The catalog is intentionally provisional while broad `GameLocation` and `Object`
entry points still require branch-level decompilation. A catalogued blocked action
is part of the denominator, but it is not readable, compilable, executable, or
training eligible.

The current baseline catalogs 138 semantic actions: 96 have an `OptionSpec` and
42 are source-attributed `catalogued_blocked` entries. There are no surface-level
unclassified or uncatalogued semantic actions, but 51 broad native entries still
require branch expansion before the denominator can be frozen.
