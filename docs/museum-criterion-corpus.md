## Public Contract

```text
build-museum-teacher-corpus --request ABS --output NEW_JSON
verify-museum-teacher-corpus --corpus ABS --output NEW_JSON
```

Request schema `museum_teacher_corpus_request.v1` contains a corpus ID and exact
`source_id`/`join_path` pairs. Outputs must be new JSON files. Each distinct join
is verified once by the original full typed verifier. No trajectory/provider
roundtrip or second native proof follows. A digest recheck rejects a join that
changes during verification; there is no path-only proof cache.

Rows retain all 95 original before/after items, pairs, candidate count, exact
native action/nonce, stacks, source digests and original save/player/total-day
split. Duplicate source IDs, paths, identical artifact copies, decision groups,
runs, nonces or action identities reject. Dates must precede Year3 and partition
hashes must match the original split. All rows share the same knowledge, full
requirement inventory and original dependency graph authorities.

One native outcome is counted per complete source, not once per preference pair.
Three independent original partitions are required for `split_complete`; that
flag never means full prior acquisition/root or formal product training.
Stored flags, removed items or copied groups do not survive public Verify.

## Original Coverage Adapter

The new `museum_terminal_corpus` source kind extends the original coverage and
reconciliation dispatch only for `complete_museum_collection`, exact method
`grandpa.direct.complete_museum_collection`, criterion
`achievement_complete_collection`. It binds current knowledge and the full95
requirement inventory before adding comparison/native partitions. It does not
change the original method, permission, dependency graph or any sibling criterion.

An executable method requires a separately verified conditional method
certificate; a corpus alone cannot promote it. The current adapter rejects such
a promotion. Next development adds that certificate through the existing local
dependency-view pattern, retaining original full acquisition/global obligations,
then collects only genuinely missing native partitions. Successful B and accepted
roots are not recollected. This is not an extra game execution system.
