## Preserve The Original Frame Contract

The shared native reader came from `3bde2048`, extracting the existing Rusty Key
wire checks for Master Angler, later reused by Skills. Its old `Read` API requires
the compiled queue/command hash to equal the action's before hash. This is not a
bug and does not mean a queue must contain exactly one item: its first item can
pass while a later, rebound frame cannot be read independently. A bounded retained
chat hash lookup found no message; original source/tests, not invented context,
establish this intent.

New `ReadQueue` first invokes the original complete queue receipt validator.
Only an accepted immutable precompiled queue (no Teacher-preference queue rewrite)
can then reuse private wire/actor/parameter/nonce/snapshot checks with the original
compiled-frame hash. Actual requests still bind each actual before frame. The
shared private parser returns a frame, not the old standalone verified-action
type; the old entry still uses its strict default. No producer or old gate changes.

Each step must match the aggregate item, exact native capture, full materialized
frame chain, nonce, observed facts, isolated environment and run. Nonces cannot
repeat. Original mechanical paths are not replaced with rewritten queue files.
Final snapshots must be the recorded capture. Physical manifest/blob/journal/gzip
hashes are retained separately from logical frame equality. The original compiler
is replayed once; an internal source result avoids repeating Teacher verification
just to expose its already-verified preference. Existing public compile APIs and
default admission are unchanged.
