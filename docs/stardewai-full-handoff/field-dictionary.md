# StardewAI Field Dictionary

This dictionary scopes fields to AI decision, execution, training, and safety needs. It is not a complete Stardew Valley data model.

Status values:

- `covered_for_read`: transparent read-side field exists.
- `covered_for_gate`: compiler/candidate gate consumes the field.
- `blocked_for_execution`: executor remains disabled or unimplemented.
- `needs_runtime_regen`: field needs a fresh runtime snapshot after next Bridge deploy.
- `needs_wiki_secondary`: local decompile evidence exists, but player-facing Wiki confirmation is still pending.
