# 任务驱动机器容量静态闭环短交接

状态：静态实现与回归完成，运行时 EVD-217 待验证，尚未新增训练准入。

本切片扩展既有 `farm.establish_supported_machine_capacity`，没有新增第二套机器执行系统。精确普通 `ResourceCollectionQuest` 或特别订单 `CollectObjective` 若只能由当前快照中确定性、零附加耗材的机器产物满足，可形成一个容量需求。已有摆放机器或背包机器会抵消需求；背包已有机器直接进入既有摆放链，否则进入既有制作链。后续摆放、任务投料、自然处理和收取继续复用现有链，并由同一个 `MachineSupportIntent` 持久化。

已闭合的失败边界：

- 任务来源必须是规范化、去重排序的精确普通收集任务或特别订单来源；
- 机器本体 ID 不能冒充机器产物需求；
- 浣熊请求、`CraftingQuest`、混合来源、随机产物、附加耗材和远程机器不进入本范围；
- 无关材料预留只有在精确槽位余量足够时才可通过，同槽冲突必须阻断；
- 任务消失或来源变化后，摆放与编译必须阻断；
- Core 1528/1528、Backend 111/111 通过。

下一步及退出条件：在 E 盘隔离存档运行隐藏、静音矩阵，覆盖普通任务和特别订单的无容量制作路径、背包机器直接摆放路径、原生摆放、精确投料、投料后任务进度不变、自然处理、原生收取后任务进度增加、意图完成，以及任务漂移和材料冲突负例。只有制品、特征行和状态变化全部通过，才能登记 EVD-217、更新能力注册表和训练 allowlist。此前不得宣称该扩展已训练准入或正式全量训练就绪。
